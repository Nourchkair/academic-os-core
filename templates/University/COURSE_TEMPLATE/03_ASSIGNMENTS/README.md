# Coursework History

This directory contains one folder per confirmed assignment and the optional course-level `Assignment_History.json` created when a coursework item is first recorded.

Use `academia history list --course "COURSE ID" --semester "TERM" --json` to read records, or the History section within this class in the Academia dashboard. Add or update a record only from an explicit student report or authorized source. Keep dates, grade, status, notes, and file references grounded in that source. Artifact paths are relative to the course folder and should point to preserved files such as drafts, final submissions, receipts, or feedback.

The course History record is academic coursework state. It is not an AI conversation log, and it does not submit coursework to the school. `06_KNOWLEDGE/Course_History.md` remains reserved for historical syllabi, assessment formats, and reports.
