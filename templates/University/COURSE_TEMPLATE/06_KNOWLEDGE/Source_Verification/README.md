# Source Verification Records

This folder stores `AI-GENERATED` provenance records for retrieved readings, chapters, books, articles, textbooks, and other potentially citable sources. The records are verification aids, not academic sources.

Create one record per retrieval or materially different version. Compare the authoritative professor-requested target with the retrieved copy field by field. Show matches, mismatches, fields not specified by the professor, unavailable metadata, non-comparable fields, source authorization, chapter/page evidence, and the final result.

Allowed result labels:

- `EXACT MATCH — HIGH CONFIDENCE`
- `PROBABLE MATCH — VERIFY MANUALLY`
- `MISMATCH`
- `NOT RETRIEVED`

Never treat a different edition, source type, or unverified copy as the assigned source. Link each record from `06_KNOWLEDGE/Source_Index.md`.
